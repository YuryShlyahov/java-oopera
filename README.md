# Java Oopera 🎭

**Java Oopera** — учебный проект на Java, посвящённый моделированию работы театра и управлению театральными постановками.

## 📌 О проекте

Проект представляет собой объектно-ориентированную модель театра, в которой реализованы различные типы спектаклей, участники постановок и взаимодействие между ними.

Приложение позволяет создавать спектакли, формировать актёрский состав, назначать режиссёров, работать с музыкальными постановками и заменять актёров.

Проект разработан в образовательных целях для практического изучения Java и принципов объектно-ориентированного программирования.

## ✨ Основные возможности

- Создание театральных спектаклей
- Поддержка различных типов постановок
- Добавление актёров в спектакли
- Просмотр актёрского состава
- Поиск актёров по фамилии
- Замена актёров в постановках
- Проверка на повторное добавление актёров
- Назначение режиссёров
- Учёт количества спектаклей у режиссёра
- Работа с музыкальными постановками
- Хранение текста либретто
- Вывод информации о постановках в консоль

## 🎭 Типы спектаклей

В проекте реализована иерархия классов для различных типов театральных постановок.

| Тип | Описание |
|---|---|
| `Show` | Базовый класс театрального спектакля |
| `MusicalShow` | Музыкальный спектакль |
| `Opera` | Оперная постановка |
| `Ballet` | Балетная постановка |

### Обычный спектакль

Базовый класс `Show` содержит общую информацию о постановке:

- Название
- Продолжительность
- Режиссёр
- Список актёров

Для управления актёрским составом предусмотрены методы добавления, поиска и замены актёров.

### Музыкальный спектакль

Класс `MusicalShow` расширяет базовый класс `Show` и добавляет:

- Автора музыки
- Текст либретто
- Возможность вывода либретто в консоль

### Опера

Класс `Opera` наследуется от `MusicalShow`.

Дополнительно содержит информацию о количестве участников хора.

### Балет

Класс `Ballet` наследуется от `MusicalShow`.

Дополнительно содержит информацию о хореографе постановки.

## 👥 Участники театра

В проекте реализована отдельная иерархия классов для участников театральных постановок.

### Основные классы

| Класс | Назначение |
|---|---|
| `Person` | Базовый класс человека |
| `Actor` | Актёр театра |
| `Director` | Режиссёр |
| `MusicAuthor` | Автор музыки |
| `Choreographer` | Хореограф |
| `Gender` | Перечисление пола участника |

Класс `Person` содержит общие характеристики:

- Имя
- Фамилию
- Пол

Класс `Actor` дополнительно содержит рост актёра.

Класс `Director` позволяет учитывать количество созданных спектаклей.

## 🚀 Запуск проекта

### Требования

Для запуска приложения необходимы:

- JDK 21 или выше
- IntelliJ IDEA или другая Java IDE

### Клонирование репозитория

```bash
git clone https://github.com/YuryShlyahov/java-oopera.git
cd java-oopera
```

### Запуск приложения

1. Откройте проект в IntelliJ IDEA.
2. Убедитесь, что настроен JDK.
3. Перейдите к файлу `src/Theatre.java`.
4. Запустите метод `main()`.

Приложение выведет в консоль информацию о созданных спектаклях, актёрском составе и результатах операций с постановками.

## 💻 Пример работы

В демонстрационном сценарии создаются следующие постановки:

- «Ничего не бойся, я с тобой»
- «Кармен»
- «Дон Кихот»

Для каждой постановки формируется актёрский состав.

После этого приложение:

1. Выводит список актёров спектаклей.
2. Заменяет актёра в одной из постановок.
3. Проверяет возможность замены актёра в другой постановке.
4. Выводит текст либретто музыкальных спектаклей.
